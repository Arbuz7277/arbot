# Arbot

**Arbot** — это шаблонный код модульного Telegram-бота на фреймворке aiogram и aiosqlite с готовой структурой и примерами.

## Цель

Arbot создан для быстрого старта разработки собственного Telegram-бота без необходимости создавать структуру проекта с нуля.

## Как запустить?

Чтобы запустить бота у себя на ПК, следуйте шагам:

1. Если требуется, создайте виртуальное окружение `python3 -m venv .venv` и войдите в него.
    - Linux: `source .venv/bin/activate`
    - Windows: `.venv\Scripts\activate`
2. Установите все необходимые библиотеки: `pip3 install -r requirements.txt`.
3. Получите токен своего бота у [BotFather](https://t.me/BotFather) и положите его в файл `.env` как `API_BOT=ВАШ_ТОКЕН`.
4. Запустите бота: `python3 main.py`.
5. При отключении нажмите `Ctrl + C`, при необходимости выйдите из виртуального окружения: `deactivate`.
